# Changelog — vaultd

## 0.1.0 — 2026-11-09

- First release: `login` (device code approved on the web), `whoami`, `search`, `read`, `run`, `inject`, `ssh-agent`, `ssh-add`.
- Two approval modes per device: approve each use, or authorize the device.
- macOS universal (signed and notarized), Windows x64, Linux x64 and ARM64.
